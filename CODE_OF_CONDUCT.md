# Community code of conduct

RuleWallet should be a constructive place to build security infrastructure in public.

## Expected behavior

- Be specific, respectful, and willing to revise a claim when evidence changes.
- Critique code and decisions, not people.
- Protect private information and use the security process for vulnerabilities.
- Welcome contributors regardless of experience, identity, background, or location.
- Disclose conflicts of interest and avoid misleading financial promotion.

## Unacceptable behavior

Harassment, threats, discriminatory language, doxxing, sexualized attention, spam, market manipulation, impersonation, and deliberate security abuse are not accepted.

Maintainers may edit or remove contributions and temporarily or permanently restrict participation. Report conduct concerns privately to the repository maintainers. Enforcement decisions should protect affected people and avoid publishing sensitive details.
